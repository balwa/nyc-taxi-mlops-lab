# app/

Given in S0: the ride-hailing backend with a stub `/predict` (static median). From S3, with `SERVING_URL` set, `/predict` asks serving (New York local hour and day, 0 = Sunday, as `contracts/features.yaml` defines) and falls back to the static median if serving is slow (300 ms), down, or has no champion yet; the response's `model` says which one answered. From S6, `POST /assist` (`contracts/assistant-openapi.yaml`) is the support assistant: it embeds the question, retrieves wiki chunks from pgvector, and asks the LLM host; `"use_wiki": false` skips retrieval, to compare answers with and without the wiki. Configuration: `LLM_HOST`, and `/secrets/rds.json` and `/secrets/langfuse.json`, which `deploy/web.sh prepare` copies from Secrets Manager. Tracing to Langfuse is on when the latter exists. From S7 the assistant may call the MCP server's tools (`MCP_URL`): which ones, and which calls may run, is yours (`ALLOWED_TOOLS`, `allow_tool_call`); every call shows in `tool_calls` and the trace.
